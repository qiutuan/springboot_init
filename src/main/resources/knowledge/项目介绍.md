# SpringBoot 脚手架项目介绍

本项目是一个基于 Spring Boot 3.5 的企业级应用脚手架，集成了用户认证（Sa-Token + RBAC）、
对象存储（MinIO / 腾讯云 COS）、Redis 缓存、WebSocket 实时通信、接口限流防重复提交、
请求日志、以及 Spring AI（通义千问）智能对话与 RAG 检索增强问答能力。

## 技术栈

- Spring Boot 3.5.x、JDK 17+
- MyBatis-Plus 3.5.x、MySQL 8
- Redis（缓存、分布式限流、会话/上下文持久化）
- Sa-Token（登录认证 + RBAC 角色权限）
- Spring AI 1.0 + Spring AI Alibaba（DashScope 通义千问）
- MinIO / 腾讯云 COS 对象存储
- WebSocket（实时消息推送与心跳）

## 目录结构

- controller：控制器层
- service：业务服务层
- mapper：MyBatis-Plus Mapper 层
- aspect：AOP 切面（日志、限流、防重复提交）
- filter：过滤器（TraceId、XSS）
- config：配置类
- security：Sa-Token 权限数据源（RBAC）
- ai：AI 能力（对话、RAG、Advisor）
- manager：对象存储等外部服务封装
- websocket：WebSocket 服务
