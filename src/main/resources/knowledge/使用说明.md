# 使用说明（快速开始）

## 环境要求

- JDK 17+
- Maven 3.6+
- MySQL 8.0+（执行 resources/sql/springboot_init.sql 初始化）
- Redis 6+
- 可选：MinIO 或腾讯云 COS

## 关键配置

数据库、Redis、MinIO 等敏感配置通过环境变量注入，例如：

- DB_PASSWORD：数据库密码
- REDIS_HOST / REDIS_PASSWORD：Redis 地址与密码
- DASHSCOPE_API_KEY：通义千问 API Key（AI 对话与 RAG 需要）

## AI 接口

所有 AI 接口都需要登录（请求头携带 Sa-Token 的 token）：

1. POST /api/ai/chat —— 非流式对话，body: { "message": "你好", "conversationId": "会话ID" }
2. POST /api/ai/chat/stream —— 流式对话（SSE），参数同上
3. POST /api/ai/rag/chat —— RAG 问答，body: { "question": "问题" }
4. POST /api/ai/rag/retrieve —— 仅检索知识库，返回命中的文档片段

多轮对话通过 conversationId 关联上下文，上下文存储在 Redis 中（2 小时过期）。

## 知识库

启动时自动加载 ./data/knowledge 目录（或 classpath:/knowledge）下的 .md/.txt 文件，
切片后向量化入库。生产环境建议接入 Redis Stack / pgvector 等持久化向量库。
